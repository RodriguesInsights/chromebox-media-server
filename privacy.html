Privacy Policy

Chromebox Media Server is a personal application used exclusively by its owner.

Google Drive Access

The application uses the Google Drive API with read-only permissions to access media files authorized by the owner.

Data Usage

Files are accessed for personal media playback over the owner's private local network.

Data Storage and Sharing

Authentication credentials are stored locally on the owner's server. Google Drive files are not sold or shared with third parties by this application.

Access Revocation

The owner may revoke application access through Google Account security settings.
